# Log of deviations from the PP-FedData spec (since v1.1)

**English** | [Tiếng Việt](SPEC_DEVIATIONS.vi.md) · Spec: [PP-FedData_Implementation_Spec.md](PP-FedData_Implementation_Spec.md)

This file records every place where the code or an actual decision **differs** from spec v1.1, with the evidence. Purpose: revise the spec once
into **v1.2 at G2** without having to remember. Every new row is added at the end of the table of its Phase. The numbers come from
`data/inventory/*.csv`, `configs/feature_decisions.yaml`, `data/interim/6class/split_manifest.json`.

> **Update 2026-10-03 (G2):** every row with status `APPROVED`/`OWN CHOICE` below has been folded into spec v1.2 (see the Change history section of `PP-FedData_Implementation_Spec.md`). This file is kept as the evidence log; no `OPEN` row remains (3.5, 3.6, 4.10, 4.11, 5.4, 5.5 were settled or handled on 2026-10-03; one follow-up remains: the `pip freeze` lock file in Phases 7-8 and the OTHER/NONE test in Phase 7).

> **Update 2026-10-05 (spec v1.3):** every `APPROVED`, `RECORDED`, `FIXED`, `HANDLED`, `CLOSED`, `DECIDED` row of Phases 6-13 has been folded into spec v1.3 (see the Change history of `PP-FedData_Implementation_Spec.md`; the spec holds only rules, the measurements and results stay in this file and in `results/`). The `OPEN` rows (6.3 done in 7.7, 6.7 optional WGAN-GP, 7.6, 13.10) and the A2-A5 work are not folded in, because they have no conclusion yet. This file is still the evidence log: the code, the reports and the tests cite its row numbers, so it is not deleted.

Status: `APPROVED` = the user agreed (G1 or in the conversation), `OWN CHOICE` = chosen by the implementer, to be confirmed by the user
when reviewing v1.2, `OPEN` = not settled.
