# Provenance of the raw data

Generated by `ppfeddata check-extraction` (module `data/extraction_check.py`); do not edit. Counts, shares, scores and hashes only, no data row.

The Kaggle release (alaaalatram/dosddos-mqtt-iot) has the authors' CSV for 48 attack captures (one more file is empty) and no CSV for the Normal captures, which the group extracted from PCAP with `tools/extract_normal_pcap.py`. Tools: tshark TShark (Wireshark) 4.4.7 (v4.4.7-0-g7980339b1630).

**Since round R** the study uses the Normal traffic extracted with the authors' export settings (section 6). Sections 2, 3 and 5 describe the first extraction (every packet, one pass), kept in `NormalData/CSV_Extracted_Split` as the reference; section 5 measured its weight on the results of the first study.

## Extraction command

```
tshark -n -r <pcap> -d tcp.port==1883,mqtt -T fields -E header=n -E separator=, -E quote=d -E escape=y -E occurrence=f -e frame.number -e mqtt.msgtype -e mqtt.qos -e mqtt.conflag.qos -e mqtt.sub.qos -e frame.time_epoch -e _ws.col.protocol -e _ws.col.Source -e frame.len -e frame.time_delta_displayed -e frame.time_relative -e frame.len -e tcp.stream -e tcp.analysis.initial_rtt -e tcp.time_relative -e tcp.len -e tcp.window_size -e tcp.flags.syn -e tcp.flags.reset -e tcp.flags.ack -e mqtt.conflag.cleansess -e mqtt.kalive -e mqtt.username_len -e mqtt.passwd_len -e mqtt.retain -e mqtt.conflag.cleansess -e mqtt.conflag.retain -e mqtt.conflag.willflag -e mqtt.willmsg_len -e mqtt.willtopic_len -e mqtt.topic_len -e mqtt.len -e _ws.col.info
```
